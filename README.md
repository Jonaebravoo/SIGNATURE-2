# CHAPTER & CO. — SIGNATURE COLLECTION: THE IVORY ATELIER (V1)

**A Love Beautifully Written.**

## About
Second Signature theme, derived from the locked Enchanted Rose Signature master. Preserves all 11 sections, navigation, maps, music behavior, RSVP demo, gallery and video. Theme-only styling is appended to `style.css`.

## Deployment
Upload the CONTENTS of this folder to the root of a GitHub Pages repository (main / root). `index.html` must be at repository root.

## Included
- Elegant ivory silk animated invitation-card welcome
- Italian-villa-inspired hero with couple photo placeholder
- Three alternating love-story chapters
- Ceremony/reception maps (internet required)
- Ten-photo gallery with lightbox and swipe
- Prenup sample video, local music MP3
- Countdown, attire palette, wedding guide, demo RSVP
- Scroll entrances and subtle floating petals

## Important limitations
- The couple photography consists of **concept-image crops** and is NOT a true high-resolution, consistent-couple photoshoot. Replace before commercial delivery.
- Backgrounds are custom-generated decorative textures; not actual photographs of an Italian villa.
- Video and music are bundled placeholders; replace with client-provided/licensed assets.
- RSVP uses browser localStorage ONLY; responses do not reach the couple. Connect a real backend for commercial use.
- Map requires an internet connection. Venue data is fictional demo information.
